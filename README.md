## Original Description

Questie-X is a fork of Questie with enhancements for custom server compatibility, featuring:

- **QuestieLearner**: An autonomous engine that learns NPC spawns, quest relationships, object locations, and item drops from combat logs and interaction events — zero configuration required.
- **Cross-link engine**: Automatically stitches connections between learned entities (item → NPC → quest).
- **Confidence system**: Multi-tier verification with match counts and automatic stale-data cleanup.
- **Universal server support**: Plugin architecture designed for any private server.

For full documentation, see [docs/index.html](./docs/index.html).
